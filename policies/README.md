# アプリのプライバシーポリシー保存先

このディレクトリには、各アプリのプライバシーポリシーを保存します。

## ファイル命名規則

アプリごとにプライバシーポリシーを作成する場合は、以下の命名規則に従ってください：

- `[アプリ名]-privacy-policy.md` (日本語版)
- `[アプリ名]-privacy-policy-en.md` (英語版)

例:
- `my-todo-app-privacy-policy.md`
- `photo-editor-privacy-policy.md`

## バージョン管理

プライバシーポリシーを更新する場合は、以下の方法を推奨します：

1. Git のコミット履歴を使用して変更履歴を管理する
2. 各ファイル内の「最終更新日」を更新する
3. 重要な変更の場合は、古いバージョンを別ファイルとして保存することも検討する

## 公開方法

作成したプライバシーポリシーは、以下のいずれかの方法で公開できます：

1. GitHub Pages を使用してホスティング
2. 自社サイトにアップロード
3. アプリ内に埋め込み

App Store および Google Play の要件を満たすため、公開URLを確保してください。
