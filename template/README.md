# テンプレートの使い方

このディレクトリには、アプリのプライバシーポリシーを作成するためのテンプレートが含まれています。

## ファイル一覧

- `privacy-policy.md` - 日本語版プライバシーポリシーテンプレート
- `privacy-policy-en.md` - 英語版プライバシーポリシーテンプレート

## 使用方法

1. テンプレートファイルをコピーして、あなたのアプリ名に合わせてファイル名を変更してください
   - 例: `my-app-privacy-policy.md`

2. テンプレート内の `[...]` で囲まれた部分を、あなたのアプリに合わせて記入してください

3. 完成したプライバシーポリシーは、`policies/` ディレクトリに保存することをおすすめします

## 記入時の注意点

- **収集する情報**: アプリが実際に収集する情報のみを記載してください
- **第三者サービス**: 使用している全ての第三者サービスをリストアップしてください
- **連絡先**: 実際に対応可能なメールアドレスを記載してください
- **日付**: 最終更新日と制定日を正確に記入してください

## App Store / Google Play への提出

プライバシーポリシーは、App Store および Google Play でのアプリ審査において必須の要素です。以下の点に注意してください：

- プライバシーポリシーは公開URLで参照できるようにする必要があります
- アプリ内からもプライバシーポリシーにアクセスできるようにすることが推奨されます
- 収集するデータの種類と利用目的を明確に記載してください
