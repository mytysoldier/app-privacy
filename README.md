# app-privacy

アプリストアに配布するアプリのプライバシーポリシーを管理するリポジトリです。

## 📋 概要

このリポジトリは、App Store や Google Play などのアプリストアに配布するアプリケーションのプライバシーポリシーを一元管理するために作成されました。テンプレートや例を活用して、簡単にプライバシーポリシーを作成・管理できます。

## 🗂️ ディレクトリ構成

```
app-privacy/
├── template/          # プライバシーポリシーのテンプレート
│   ├── privacy-policy.md      # 日本語テンプレート
│   ├── privacy-policy-en.md   # 英語テンプレート
│   └── README.md              # テンプレートの使い方
├── policies/          # 各アプリのプライバシーポリシー保存先
│   └── README.md
├── examples/          # プライバシーポリシーの使用例
│   ├── sample-app-privacy-policy.md
│   └── README.md
└── README.md          # このファイル
```

## 🚀 使い方

### 1. テンプレートを選択

`template/` ディレクトリから、言語に応じたテンプレートを選択します：

- **日本語版**: `template/privacy-policy.md`
- **英語版**: `template/privacy-policy-en.md`

### 2. テンプレートをコピー

テンプレートファイルをコピーして、アプリ名に合わせてファイル名を変更します：

```bash
cp template/privacy-policy.md policies/my-app-privacy-policy.md
```

### 3. 内容を編集

テンプレート内の `[...]` で囲まれた部分を、あなたのアプリに合わせて記入します：

- アプリ名
- 収集する情報の種類
- 利用する第三者サービス
- 連絡先情報
- 最終更新日

### 4. プライバシーポリシーを公開

作成したプライバシーポリシーを以下のいずれかの方法で公開します：

- GitHub Pages でホスティング
- 自社 Web サイトにアップロード
- アプリ内に組み込み

## 📝 プライバシーポリシーに含めるべき項目

App Store および Google Play の要件を満たすため、以下の項目を含めることをおすすめします：

1. **収集する情報** - どのような情報を収集するか
2. **情報の利用目的** - 収集した情報をどのように使用するか
3. **情報の共有** - 第三者と情報を共有するか
4. **第三者サービス** - 使用している分析ツールや広告サービス
5. **データの保管** - セキュリティ対策について
6. **ユーザーの権利** - データへのアクセスや削除の権利
7. **お問い合わせ** - 連絡先情報

## ⚠️ 注意事項

- プライバシーポリシーは、アプリの実際の動作と一致している必要があります
- 収集していない情報について記載しないでください
- 法律の専門家に確認することをおすすめします
- 定期的に見直し、必要に応じて更新してください
