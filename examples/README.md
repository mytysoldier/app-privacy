# 使用例

このディレクトリには、プライバシーポリシーの具体的な使用例が含まれています。

## ファイル一覧

- `sample-app-privacy-policy.md` - サンプルアプリのプライバシーポリシー例

## 使用方法

これらの例を参考にして、あなたのアプリに適したプライバシーポリシーを作成してください。

### サンプルアプリの例について

`sample-app-privacy-policy.md` は、以下の特徴を持つアプリを想定しています：

- 個人を特定できる情報は収集しない
- Google Analytics でアクセス解析を行う
- Firebase でクラッシュレポートを収集する
- 13歳以上を対象とする

あなたのアプリの実際の仕様に合わせて、内容をカスタマイズしてください。
